# nvim

Base: [LazyVim](https://github.com/LazyVim/LazyVim) — personal config in `lua/config/`, plugin overrides in `lua/plugins/`.

- Literal (fixed-string) grep in all pickers
- `Space Space` search everywhere, `Alt+←/→` jump back/forward
- vim-tmux-navigator, harpoon, neotest, DAP (go/python/ruby)
- Groovy LSP jar in `lsp-servers/`
